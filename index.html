生成原理與使用提醒

離線引擎使用七種模板：對比批判、價值昇華、主體優先、願景描繪、原則條件、方法循環、抽象概念解釋。它會依常見主題關鍵字選擇相關詞彙，其他主題使用通用回退詞庫；不是完整語意理解，偶爾可能出現不自然的語句。空洞程度低時加入示範性的具體步驟，不能當作已驗證政策或專業建議。

本檔案不儲存 API Key，也不需要開發者帳號。Puter.js 是第三方服務，線上功能及費用可能變動。離線模式無外部請求。為保障隱私，請勿在使用線上模式時輸入機密或個人資料。

版本 1.0 · 所有離線邏輯與樣式均包含在本 HTML 中。iPhone 可透過支援本機 HTML 的瀏覽器或檔案檢視工具開啟；線上模式建議透過 HTTPS 網頁開啟。
